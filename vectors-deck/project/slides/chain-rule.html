Цепочка векторов: правило многоугольника

Векторы идут цепочкой → сумма идёт из самого начала в самый конец:

AB + BC + CD + DE = AE

Лайфхак: одинаковые буквы-соседи «сокращаются»:

AB + BC = AC

Цепочка вернулась в начало → сумма равна нулю: AB + BC + CA = 0.

Слагаемые можно переставлять: BC + AB = AB + BC = AC.

Этот приём с буквами решает большинство задач на упрощение: переставь слагаемые так, чтобы получилась цепочка, и сократи средние буквы.
