Скалярное произведение

Скалярное произведение векторов — это число:

a · b = |a| · |b| · cos α

В координатах

Если a {x₁; y₁} и b {x₂; y₂}, то

a · b = x₁x₂ + y₁y₂

Пример: |a| = 2, |b| = 3, α = 60°. Тогда a · b = 2 · 3 · ½ = 3.

Что из этого следует

  • a · b = 0 — векторы перпендикулярны (и наоборот);
  • a · b > 0 — угол острый;
  • a · b < 0 — угол тупой;
  • a · a = |a|²;
  • cos α = (a · b) / (|a| · |b|).
Не путай: k·a (число на вектор) — это вектор, а a·b (вектор на вектор, скалярно) — это число.
