Правило треугольника

  1. Нарисуй вектор a.
  2. От конца вектора a отложи вектор b.
  3. Соедини начало a с концом b — это и есть a + b.

AB + BC = AC

для любых трёх точек A, B и C

Главное: конец первого = начало второго
