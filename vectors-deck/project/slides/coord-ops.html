Тема 7 · Координаты

Действия с векторами в координатах

Пусть a {2; −1} и b {−3; 4}. Всё делаем отдельно с x и отдельно с y:

Действие

Правило

Пример

Сложение

складываем x с x, y с y

a + b = {2 + (−3); −1 + 4} = {−1; 3}

Вычитание

вычитаем x из x, y из y

a − b = {2 − (−3); −1 − 4} = {5; −5}

Умножение на число

умножаем каждую координату

3a = {3 · 2; 3 · (−1)} = {6; −3}

Длина

|a| = √(x² + y²)

|b| = √((−3)² + 4²) = √25 = 5

Комбо:

2a − b = {4; −2} − {−3; 4} = {7; −6}

Минус на минус даёт плюс: 2 − (−3) = 5. Именно здесь чаще всего ошибаются, поэтому всегда ставь скобки вокруг отрицательных чисел.
