Тема 5 · Умножение на число

Свойства: как с обычными числами

Три правила

(kl)a = k(la)

2 · (3a) = 6a

(k + l)a = ka + la

2a + 5a = 7a

k(a + b) = ka + kb

3(a + b) = 3a + 3b

Раскрываем скобки и приводим подобные

2(a + b) − 3(a − b) =

= 2a + 2b − 3a + 3b = −a + 5b

Коллинеарность

Если b = ka, то векторы a и b коллинеарны.

И наоборот: если a ≠ 0 и b коллинеарен a, то найдётся такое число k, что b = ka.

Коллинеарны = один получается из другого умножением

С векторами можно обращаться почти как с буквами в алгебре: раскрывать скобки, приводить подобные, выносить общий множитель.
