Шпаргалка: координаты и бонус

Координаты вектора

AB {x₂ − x₁; y₂ − y₁} — конец минус начало.

Длина

|a| = √(x² + y²)

Сумма и разность

{x₁ + x₂; y₁ + y₂} и {x₁ − x₂; y₁ − y₂}

Число × вектор

ka = {kx; ky}

Середина отрезка

((x₁ + x₂)/2; (y₁ + y₂)/2)

Коллинеарность

x₁ / x₂ = y₁ / y₂ — координаты пропорциональны.

Скалярное произведение

a · b = |a| · |b| · cos α = x₁x₂ + y₁y₂

Перпендикулярность

a · b = 0

Угол

cos α = (a · b) / (|a| · |b|)

Оранжевые карточки — бонусная тема (скалярное произведение). Если её не было в программе, их можно не учить.
